# 错题本与重练

对应 Issue #66。错题本入口位于岗位页和报告页，前端路径为 `/wrongbook`。

## 保存规则

- 测评提交成功时，按选项集合完整一致的规则判断对错，只收集答错的题目。收集与原提交状态、评分报告在同一事务中保存；失败时回滚本次提交，已保存草稿保留。
- 一次测评的一道错题对应一条记录，以用户、测评和题目编号唯一约束。重复提交不会重复收集。
- 同一道题在不同测评中分别记录，保留各自岗位、原答案、提交时间和题目版本，避免把不同来源或版本混在一起。
- 题干、选项、正确答案、解析、知识点和来源均从该次测评的题目快照保存。以后更新题库，不改变错题本里的旧题。
- 新增迁移 `005_wrongbook.sql`，不修改旧迁移，不覆盖历史测评。不自动回填功能启用前的旧测评；已有账号需完成一次新的测评后开始收集。

## 接口

所有接口要求登录。修改操作沿用现有 CSRF 校验；不存在或不属于当前用户的错题统一返回 404。

### `GET /api/wrong-questions`

- 可选 `roleId`、`dimension`、`topicId`。
- `status`：`review`（默认待复习）、`mastered`、`all`。
- `limit` 默认 20，上限 100；`offset` 默认 0。按收集时间和编号倒序返回。
- 返回 `items`、筛选后的 `total`、`limit`、`offset`、当前用户的各状态 `counts` 和实际记录对应的筛选项 `filters`。
- 列表项包含来源测评、岗位、维度、知识点、题干、版本、掌握状态、重练次数和最近一次重练结果。

### `GET /api/wrong-questions/{id}`

返回列表项字段、`question` 题目快照、`originalAnswer` 原测评答案，以及 `practices` 重练记录（时间倒序）。只有已经提交并被收集的错题可以读取答案和解析；进行中测评接口继续沿用原有白名单，不返回正确答案或解析。

### `POST /api/wrong-questions/{id}/practice`

请求：`{"requestId":"UUID v4","selected":["A","C"]}`。

- 校验单选/多选、选项范围、重复选项和空答案。按保存的错题快照判定，不读取最新版题库。
- 返回本轮 `result` 和更新后的错题详情 `item`。每次新的重练生成新的 `requestId`。
- 同一个 `requestId` 与相同答案重试，返回同一条练习记录，不增加次数；同一请求编号更换答案返回 409。
- 练习记录单独保存，不修改原测评答案、成绩、报告或提交时间。

### `PATCH /api/wrong-questions/{id}`

请求：`{"mastered":true}` 或 `{"mastered":false}`。

掌握状态由用户确认。重练答对不会自动标记已掌握；移回待复习后仍保留所有重练记录。重新登录和普通重启后可继续读取。

## 页面行为

支持岗位、维度、知识点和掌握状态筛选，列表超过 20 条时分页。桌面左右显示列表与详情，窄屏选择题目后显示详情，可返回列表。

重练时暂时隐藏原答案、正确答案和解析；提交重练后展示结果并恢复解析。加载、保存失败时给出提示并允许重试，失败重试保留本轮选择及请求编号。
